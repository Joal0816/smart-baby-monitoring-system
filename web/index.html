Connect to backend

Use the app bearer token from the backend configuration. Keep the device token on the board.

The token stays in page memory and clears when you close or reload this page.

This browser connection is for local or trusted development use. A shared public site needs a server-side authenticated proxy.

Setup and recovery steps
  1. Start the FastAPI service and set MONITOR_APP_TOKEN. The default local URL is shown above.
  2. Enter the same app token and a device ID registered with the backend.
  3. Configure the board with its separate device token and send telemetry. The dashboard uses server-received timestamps.

If connection fails, check the backend health, app token, device ID, and allowed browser origin in MONITOR_ALLOWED_ORIGINS. For LAN access, use a trusted HTTPS certificate. If readings stop, check board power and Wi-Fi, then the service logs.
